# CBRA Briefing

CBRA is a Nextflow DSL2 pipeline for rare-disease analysis of SNVs, INDELs, structural variants,
and copy-number variants from targeted, exome, and whole-genome sequencing data. It combines
nf-core modules with local workflows for mapping, variant calling, annotation, and reporting.

Development commands run in a user-selected Slurm allocation with the `nf-dev` Conda environment.
